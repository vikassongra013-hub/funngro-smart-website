# Funngro Smart Website — Assignment Project

This is an ORIGINAL two-page concept website built for a web-development assignment.

Pages:
1. index.html — For Teens
2. brands.html — For Brands

Files:
- style.css — responsive UI and components
- script.js — smooth-scroll behavior
- seo-audit-report.md — SEO audit/report template and findings
- README.md — setup instructions

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Use the navigation to open brands.html.
4. For live deployment, upload the folder to GitHub Pages, Netlify, Vercel, or another static host.
5. Replace the example.com canonical URLs with the final live URL before submission.

Important:
This is a concept/assignment website, not an official Funngro site. Official links are provided where appropriate.
